Sobre mim

Desenvolvedor focado em
backend e produto

Sou desenvolvedor backend com foco em .NET e construção de APIs robustas, seguras e escaláveis. Tenho experiência no desenvolvimento de sistemas voltados para regras de negócio complexas, integrações entre serviços e organização de código utilizando princípios como SOLID, Clean Architecture e boas práticas de engenharia de software.

Mais do que apenas escrever código, meu foco está em entender o problema e construir soluções que realmente gerem valor, seja melhorando performance, facilitando manutenção ou garantindo escalabilidade. Também tenho experiência com frontend e mobile, o que me permite ter uma visão mais completa do produto e colaborar melhor com outras áreas.

Trabalho principalmente com .NET, ASP.NET Core, HTML, CSS, JavaScript e integrações via APIs REST. Tenho familiaridade com arquitetura de sistemas, autenticação (JWT), modelagem de dados e organização de projetos voltados para crescimento e manutenção a longo prazo.

.NET / C# ASP.NET Core Azure SQL Server REST APIs Clean Architecture HTML / CSS JavaScript
